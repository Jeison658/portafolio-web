Portafolio de Desarrollo de Contenidos Digitales

¿Qué son los contenidos digitales?

Los contenidos digitales son recursos creados en formato digital como videos, imágenes, páginas web y presentaciones interactivas que ayudan a compartir información.

Importancia de las páginas web educativas

Las páginas web educativas permiten aprender de manera más dinámica e interactiva, facilitando el acceso a recursos y actividades desde cualquier lugar.

Herramientas utilizadas

  • HTML
  • CSS
  • GitHub Pages
  • Genially
