Portafolio de Desarrollo de Contenidos Digitales

¿Qué son los contenidos digitales?

Los contenidos digitales son recursos creados en formato digital como videos, imágenes, páginas web y presentaciones interactivas que ayudan a compartir información.

Importancia de las páginas web educativas

Las páginas web educativas permiten aprender de manera más dinámica e interactiva, facilitando el acceso a recursos y actividades desde cualquier lugar.

Herramientas utilizadas

  • HTML
  • CSS
  • GitHub Pages
  • Genially

Mis Juegos en Scratch

Laberinto

Juego de exploración donde el jugador debe encontrar la salida atravesando diferentes caminos y obstáculos.

Quiz Matemático

Un dinosaurio realiza preguntas matemáticas mientras el jugador responde correctamente para avanzar.

Sistema Solar

Aventura interactiva donde el jugador viaja por los planetas aprendiendo sobre el sistema solar.

Bosque Mágico

Cuento interactivo ambientado en un bosque encantado lleno de decisiones.

Caza Palabras

Juego educativo donde el jugador lee las palabrasen en las burbujas para escribir la palabra igual.

Mezcla Reacciones

Juego dinámico donde distintos elementos generan diversas mezclar y con cada mezcla viene una pregunta.
